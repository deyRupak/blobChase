# 👻 Catch The Blob, If You Can

**Can you?**

A tiny supernatural blob with one simple rule.

**Catch the blob.**

Chase it. Corner it. Get close.

It'll always stay just out of reach.

Then wonder:

> *"Why am I still chasing this thing?"*

## 🎮 How to play


**Chase.** Move your cursor toward the blob.

**Get close.** It'll run.

**Keep chasing.** It won't let you win.
